# Professional Weather Station in C++ — IoT Метеостанція на ESP8266

Повноцінна професійна IoT-метеостанція та шлюз автоматизації на базі мікроконтролера **ESP8266 (Wemos D1 mini)**, написана на **C++ (PlatformIO)**. Проєкт поєднує стабільну роботу з периферією без блокування потоку, надійне керування підключенням до Wi-Fi через машину станів (State Machine) та швидку роздачу сучасного односторінкового вебзастосунку (SPA) з Flash-пам'яті мікроконтролера.

---

## 🚀 Основні особливості

* **State-Machine Wi-Fi Архітектура:** Захищене та неблокуюче підключення до мережі з автоматичним перезавантаженням при тривалій втраті зв'язку.
* **LittleFS файлова система:** Ефективне зберігання та роздача веб-інтерфейсу (`index.html`, `style.css`, `app.js`) безпосередньо з Flash-пам'яті плати (використано схему розмітки розділів `4m1m`).
* **Неблокуюче опитування датчика:** Зчитування даних з датчика **DHT11 / DHT22** за допомогою системних таймерів `millis()`, що запобігає спрацьовуванню сторожового таймера (WDT resets).
* **REST API (JSON):** Динамічна передача телеметрії (температура, вологість, аптайм системи) у форматі JSON за допомогою бібліотеки `ArduinoJson v7`.
* **SPA Fallback:** Повна підтримка маршрутизації односторінкового інтерфейсу для безшовного оновлення даних у реальному часі.

---

## 🛠 Апаратне підключення

| Компонент | Пін датчика / модуля | Пін Wemos D1 mini | Пін ESP8266 GPIO | Примітка |
| :--- | :--- | :--- | :--- | :--- |
| **DHT11 / DHT22** | VCC | 3.3V | - | Живлення датчика |
| **DHT11 / DHT22** | GND | GND | - | Загальна земля |
| **DHT11 / DHT22** | DATA | D4 | GPIO 2 | Пін даних із підтягуючим резистором |
